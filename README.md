# 금고곰 (Geumgogom)

내 정보를 잠금 뒤에. — 카드·계좌·통관부호·주소·와이파이 비밀번호를 기기 안에 암호화 보관하고 바로 꺼내 쓰는 iOS 앱.

- 매번 직접 입력해야 하는 정보(자동입력이 안 되는 것들)를 한곳에 모읍니다.
- 카드번호·주소는 **조각별로 복사**, 복사한 값은 정해진 시간 뒤 자동으로 지워집니다.
- 카드·통장을 **촬영하면 번호를 읽어** 채워 넣습니다. 인식은 기기 안에서만 이뤄집니다.
- 암호와 Face ID로 잠급니다.
- **서버가 없습니다.** 통신 기능 자체를 넣지 않았습니다.
